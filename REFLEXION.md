## Pregunta 1
Durante el desarrollo de este laboratorio aprendí a configurar un entorno de servidor web local utilizando XAMPP con Apache y MySQL. Comprendí la estructura básica de ejecución de scripts PHP del lado del servidor, cómo integrar la base de datos MariaDB para realizar consultas de conteo y verificación de versión, y la importancia de organizar adecuadamente las variables de entorno y archivos de configuración seguros dentro del proyecto.

## Pregunta 2
La diferencia principal entre embedding HTML dentro de PHP y procesar lógica pura radica en la separación de responsabilidades. PHP me permite embeber código para renderizar contenido dinámico directamente en etiquetas HTML usando estructuras como echo o sintaxis corta, mientras que los scripts de procesamiento lógico ejecutan código en el servidor, gestionan arreglos, leen datos de la base de datos y retornan respuestas en formatos estructurados como JSON.

## Pregunta 3
La manipulación de variables y arreglos en PHP me permitió estructurar la información del estudiante de forma clara y organizada. Utilicé arreglos asociativos para manejar pares de clave-valor específicos de la asignatura y arreglos indexados para listar las tecnologías web. Además, el uso de funciones como gettype() y htmlspecialchars() garantizó la correcta tipificación de los datos y la seguridad contra inyecciones XSS al renderizar en el navegador.
